# Internship Alert Tool

Automates internship application tracking by reading placement emails and scheduling deadlines on Google Calendar.

## Current Status
- Google OAuth authentication working
- Gmail & Calendar APIs enabled
- Can fetch and display gmail metadata
- Can filter by sender 
- Reads and decodes HTML and plaintext email bodies

## Tech
- Python
- Gmail API
- Google Calendar API
- BeautifulSoup Web Scraper
- SQLite Database
